## Вход

## Сделать
- Стратегии `crown_all`, `vassal_all`, `warmonger`, `builder` как наборы весов для `AutoChooser` в `data/strategies.ron`.
- `cli batch --runs N --strategy X [--seed-start S]`: N партий с seed S..S+N, правление автоматом по стратегии, симуляция, счёт. Вывод CSV: seed, reign_years, dynasty_years, score, fall_reason, early_death. Сводка в stdout: медиана и квартили лет династии, счёта, длины правления; доля ранней смерти; частоты причин падения.
- `cli trace --seed N --script path.ron`: для каждой записи хроники печатает цепочку «решение (тик, тег, цель) → метка (вес) → событие».
- Калибровка: подобрать `rules.ron` и `score.ron` так, чтобы выполнялись критерии: ранняя смерть ≤ 10% на `neutral`; медиана правления 25–40 лет; медианы счёта `crown_all`, `vassal_all`, `warmonger` расходятся ≥ 15% между соседними; доминирующие причины падения у трёх стратегий различаются.
- `docs/calibration.md`: таблицы прогонов до и после, итоговые значения, что не удалось и почему.
