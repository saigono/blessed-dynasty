# Этап 16. Законы наследования

## Контекст
Прочитай CLAUDE.md, DESIGN.md (5.4, 7), docs/calibration.md, `data/rules.ron` (`heirs.laws`), `crates/core/src/sim.rs` (`next_heir`, `crown`, `succession`) и `data/events/heirs.ron`. Этапы 12–15 влиты.

Сейчас закон только сдвигает претензии наследников, трон получает наследник с наибольшей претензией. Законов три: первородство, выборный и «без закона». Последний недостижим. Игрок закон сменить не может, это делает только вариант «Уступить совету баронов».

Решение пользователя: смена закона — действие игрока, рычаг основателя на поколения вперёд. Сделать все законы из списка ниже.

## Вход
main после этапа 15. Сигнатуры прошлых этапов по возможности не менять. Нужное поле добавляй с `#[serde(default)]` и объясняй в отчёте.

## Сделать
- **Пол наследника.** Поле `Heir.sex`, по умолчанию случайный при рождении, с вероятностью из данных. Пулы имён в `names.ron` раздельно по полу. Пресет задаёт пол явно. В UI пол показан.
- **Законы.** Каждый описан в `heirs.laws`: флаг, `name`, `description`, правило выбора наследника, пороги спора. Законы:
  - **Абсолютное первородство:** старший ребёнок, пол не важен. Как сейчас.
  - **Мужское первородство:** старший сын. Дочь наследует, только если сыновей нет.
  - **Салический закон:** только мужчины. Без сыновей трон идёт к мужчине боковой линии. Если мужчин нет вовсе, династия пала (NoHeir).
  - **Лествичное право (сеньорат):** старший в роду. Сначала братья правителя по старшинству (боковая линия, `World.line_from`), потом его дети. На трон приходит взрослый, но чаще спор: дети умершего против дяди.
  - **Выборный закон:** самый способный. Претензия идёт от способности, как сейчас. Знать довольнее, легитимность ниже.
  - **Разделение:** старший получает корону. Каждый следующий сын при воцарении получает одну коронную провинцию и становится вассалом, его дом носит его имя, а сила дома берётся из данных. Провинции раздаются от дальних к столице, столица остаётся у короны. Риск распада растёт, знать довольна.
  
  Кто наследует, решает одна функция по полю `rule` закона: enum с вариантами выше, не трейт. Числа и тексты живут в данных.
- **Действие «Сменить закон».** Доступно игроку, по одному целевому закону.
  - Цена и длительность в годах берутся из данных.
  - Пока идёт смена, накладывается сопротивление: знать или церковь, в зависимости от закона.
  - По завершении: флаг нового закона, сдвиг осей, претензии наследников пересчитываются постепенно, как сейчас.
  - Нельзя, пока идёт спор о престоле.
  - Автомат в симуляции тоже может сменить закон по весам.
- Вариант «Уступить совету баронов» оставить, он ведёт к выборному закону.
- Хроника. Смена закона — запись. Раздел земель при воцарении — запись «Земли поделены между братьями».
- UI. Подсказка закона из этапа 13 берёт `name` и `description`. Действие «Сменить закон» выбирает целевой закон из списка, у каждого видны его описание и цена.
- **Калибровка.**
  - Для каждого закона 1000 династий `neutral` со стартом на этом законе: медиана лет, причины падения, доля споров. Таблица в docs/calibration.md.
  - У каждого закона должен быть свой профиль риска: ни один не лучше всех по всем строкам.
  - Критерии 08b выполнены на стартовом законе.

## Не делать
- Новые оси. Склонение имён.

## Приёмка
- По тесту на каждый закон: заданный набор наследников (пол, возраст, линия, способность) даёт известного наследника.
- Тест: салический закон без мужчин даёт NoHeir.
- Тест: разделение отдаёт младшим сыновьям по провинции, столица остаётся у короны.
- Тест: смена закона стоит денег и лет, ставит флаг по завершении, недоступна при споре.
- Тест: пол новорождённого детерминирован при заданном seed.
- Таблица профилей законов в docs/calibration.md.
- Смена закона проходится мышью в браузере без ошибок в консоли.
