# Плейтест 1

Статус: **плейтест с людьми не проведён.** Заполнена только автоматическая проверка
критериев среза (DESIGN.md, раздел 9). Ответы тестировщиков, выводы и список правок
появятся после партий по анкете `docs/playtest-form.md`.

## Автоматическая проверка критериев среза

Данные: main после этапов 8b и 10b плюс этап 11 (баланс не менялся). CLI собран в release.
Партия основателя играется стратегией CLI: `neutral` (средний вариант каждого события,
без действий) или `sim::AutoChooser` с весами `data/strategies.ron`. Это замена человека:
число решений и время чтения у живого игрока будут другими.

Как воспроизвести:

```
cargo build --release -p cli
for s in neutral crown_all vassal_all warmonger; do
  for seed in $(seq 0 99); do ./target/release/cli run --seed $seed --strategy $s --json; done
done          # из каждого JSON: decisions, tick, score.total, chronicle.fall/years/entries
cargo test --workspace
```

### Длина партии в решениях (100 seed на стратегию, квартили 25 / 50 / 75%, максимум)

| Стратегия | Решений | из них событий | действий | Лет правления | Записей хроники |
|---|---|---|---|---|---|
| neutral | 22 / 29 / 36, max 62 | 22 / 29 / 36 | 0 | 25 / 33 / 40 | 42 / 56 / 68 |
| crown_all | 32 / 41 / 57, max 91 | 21 / 28 / 38 | 10 / 14 / 19 | 24 / 33 / 44 | 33 / 54 / 71 |
| vassal_all | 37 / 48 / 61, max 92 | 25 / 32 / 43 | 13 / 16 / 19 | 29 / 38 / 49 | 37 / 59 / 77 |
| warmonger | 32 / 47 / 68, max 107 | 21 / 31 / 45 | 11 / 16 / 23 | 21 / 31 / 45 | 60 / 75 / 83 |

Игрок, который действует, принимает около 40–50 решений, плюс по нажатию «Подождать год»
на каждый год правления (около 33). Итого около 80 действий в интерфейсе и около 55 записей
хроники. На 60 минут это 45 с на действие, если хронику читать 10–15 минут. Оценка
правдоподобна, но время партии меряет только плейтест.

### Различимость трёх стратегий (те же 100 seed)

| Стратегия | Счёт 25 / 50 / 75% | Лет династии 25 / 50 / 75% | Причины падения |
|---|---|---|---|
| crown_all | 9516 / 17524 / 20638 | 136 / 243 / 300 | Usurped 60, Alive 38, NoHeir 1, NoCrownLand 1 |
| vassal_all | 7649 / 11003 / 16668 | 118 / 168 / 282 | NoCrownLand 40, Usurped 32, Alive 23, NoHeir 4, CapitalLost 1 |
| warmonger | 22580 / 28372 / 32598 | 272 / 300 / 300 | Alive 70, Usurped 24, NoHeir 6 |

Медианы счёта: `vassal_all` < `crown_all` (+59%) < `warmonger` (+62%), доминирующие причины
падения разные (NoCrownLand / Usurped / Alive). На 1000 seed то же самое
(`docs/calibration.md`: 10697 / 17928 / 28936, +68% и +61%).

### Повтор по seed

- `cli run --seed 42 --script data/scripts/abdicate.ron` дважды: вывод совпадает байт в байт
  (хроника, «Династия: 9 лет, правителей 2, конец Usurped», «Счёт: 686»).
- Тесты: `ui::tests::the_same_seed_and_choices_give_the_same_chronicle` (тот же seed и выборы
  через интерфейс дают ту же хронику и счёт, другой seed даёт другую),
  `core::game::tests::replay_is_deterministic`, `cli::tests::replay_matches_the_game`.
- Ссылка: `ui::tests::a_link_shows_the_same_chronicle_and_score_elsewhere` (партия
  кодируется в `#p=...`, новое приложение из встроенных данных открывает её на экране итога
  с той же хроникой, счётом и журналом), `core::link::tests::a_journal_of_80_decisions_comes_back_the_same`.
