# Игра как артефакт

Веб-версия игры публикуется артефактом на claude.ai, по одной постоянной ссылке.

Ссылка: _(впишет координатор)_

## Сборка

```
scripts/game-bundle.sh            # в target/game-artifact/
scripts/game-bundle.sh some/dir   # в другой каталог
```

Скрипт делает `trunk build --release --public-url ./` в отдельный каталог. Пути к файлам
в `index.html` относительные, поэтому страница работает под любым адресом. В конце скрипт
печатает файлы и их размеры: `index.html`, JS-обвязку и wasm (этап 29b: 14.3 МБ, из них 3 МБ картинки событий, вшитые `include_bytes!`).

## Приёмка этапа с UI

После слияния этапа, который трогает `crates/ui`, координатор на `main`:

1. Запускает `scripts/game-bundle.sh`.
2. Публикует `target/game-artifact/index.html` с остальными файлами каталога рядом (Artifact,
   `files`) по той же ссылке, что выше, а не новым артефактом.
3. Открывает ссылку и проверяет, что игра запускается и в консоли нет ошибок.

Агент этапа сам игру не публикует.
