# Этап 6. Симуляция и хроника

## Контекст
Прочитай CLAUDE.md и DESIGN.md (раздел 7 целиком). Этапы 0–5 завершены.

## Вход
Ветка main после этапа 5. Типы `Game`, `World`, `Step`, `ReignEnd`, `Decision`, `Event`, `Effect`, `War`, `Heir`. Сигнатуры не менять.

## Сделать
- `sim::run(reign_end: ReignEnd, data: &Data, rng: Rng) -> Chronicle`. Внутри тот же `Game`, но выбор делает `AutoChooser`. Правление игрока и симуляция используют одну машину правил.
- `AutoChooser`: оценка варианта как взвешенная сумма эффектов по чертам правителя (`greedy`, `cautious`, `warlike`, `pious`), веса черт в `rules.ron`, плюс шум из `Rng`. Действия: раз в год из `available_actions` выбирается лучшее по тем же весам или ничего.
- Наследование: `succession(&World, &mut Rng) -> Option<Ruler>`. Кандидат по закону наследования и `claim`; черты из `ability`, статуса и случайности; возраст = возраст наследника. `None` → падение. При наследнике младше порога ставится флаг `regency` на N лет.
- События симуляции в `data/events/sim.ron` (схема этапа 2, вес растёт при плохих осях): `vassal_revolt` (вассал с низкой лояльностью и силой выше короны в его провинциях; исход: провинции отпадают во `Foreign` новый или `Holder::Vassal` независимый, помечаем флагом), `invasion` (сосед в стойке `Expand`, ведёт в цепочку войны), `succession_crisis` (несколько претендентов, низкая легитимность), `disaster` (наводнение, мор: население и доход вниз), `decline` (долго низкая стабильность), `golden_age` (долго высокие оси).
- Падение: нет наследника, столица не у короны, флаг `usurped`, провинций короны 0. Кап 500 лет с пометкой `alive`.
- `Chronicle { entries: Vec<ChronicleEntry>, fall: FallReason | Alive, years: u32, rulers: Vec<RulerRecord> }`, `ChronicleEntry { tick, text, importance, causes: Vec<CauseTag>, snapshot: World }`. Записи: каждое событие с `importance >= threshold`, смена правителя, потеря и приобретение провинции всегда.
- Причинность: `CauseTag { decision_idx, weight: Fx }`. Каждый `Decision` при применении помечает затронутые оси, провинции и флаги меткой (`World.marks: BTreeMap<MarkKey, Vec<CauseTag>>`), вес затухает по годам на коэффициент из `rules.ron`. Событие симуляции собирает метки с осей, провинций и флагов, которые входят в его `when`. Текст намёка — шаблон из `data/hints.ron` по `cause_tag` главной причины, подставляется в `text`.
- Снимок `World` в каждой записи. Оптимизацию не делать, пока не упрёмся в память.

## Приёмка
- Golden-тест: seed 42 + скрипт решений A → хроника с зафиксированными `years`, `fall` и первыми пятью `text`.
- Тест: симуляция всегда завершается, 1000 прогонов по разным seed без паники, `years <= 500`.
- Тест: при правлении, где игрок раздал три провинции одному вассалу, у записи `vassal_revolt` в `causes` есть метка с `cause_tag == "grant_province"`.
- Тест: `succession` при пустом списке наследников возвращает `None`, хроника заканчивается `FallReason::NoHeir`.
