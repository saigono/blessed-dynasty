# Этап 29. Интерфейс «карта как меню» на старинной карте

## Контекст
Прочитай CLAUDE.md, DESIGN.md и `Плейтест.md` целиком. Затем `crates/ui/src/main.rs` и `assets/README.md`. Этапы до 28 влиты: карта большая, около 40 провинций, на ней есть империя.

Макеты лежат на холсте https://claude.ai/artifact/J6EauCBwmtMyb4XBhYra3Y, читать через `Artifact` action `read` с `path`:
- `project/Context.dc.html` и `project/Cards.dc.html`: вариант B, «карта как меню». Компоновку берём из него.
- `project/RasterMap.dc.html` и `project/RasterLugovo.dc.html`: ряд B5, растровая старинная карта. Отрисовку берём из него. Там же видно, как ленты кладутся вдоль линий.
- `project/SpriteMap.dc.html`: ряд B4, раскладка спрайтов.

Холст — это макет: геометрию, цифры и тексты бери из игры.

Владелец выбрал B и старинную карту в манере Carta Marina. Изометрию отверг. После B5 оставил замечания:
- текст должен целиком влезать в подложку там, где она есть (картуш, лента, табличка);
- гербы ориентированы по тексту своей подписи и стоят на одной линии;
- линейка-шкала внизу не нужна.

## Вход
main после этапа 28. Ассеты в `assets/sprites` уже нарезаны, исходники в git не лежат. Новые поля добавляй с `#[serde(default)]`.

## Сделать
- **Компоновка B.**
  - **Шапка:** казна, армия, земли, «Дела короны: свободно N из M», «Родословная», «Подождать год».
  - **В центре карта.** Длинная боковая панель действий уходит.
  - **Клик по своей провинции** открывает карточку провинции в правой колонке. В ней указы для этой земли: построить, пожаловать и т. д. У каждого указа видны цена, срок и эффекты. Недоступный указ показан с причиной.
  - **Клик по соседу** (по его земле или подписи) открывает карточку соседа. В ней отношение и сила, война с выбором провинции и сравнением сил, брак с шансом или причиной отказа, субсидия (этап 28).
  - **Внизу полоса двора:** правитель, наследники, супруги. Клик по человеку открывает его карточку: закон наследования, брак, назначение наследника.
  - **Указы без цели** (законы, канцелярия и т. п.) — в карточке королевства. Она открывается кликом по своему гербу или картушу.
  - **Правая колонка:** выбранная карточка, под ней «Итоги года» с вестями.
  - **Окно события с выбором** остаётся модальным, как сейчас.
  - Всё, что сейчас в боковой панели, должно найтись в одной из карточек. Ничего не теряется.
- **Старинная карта из растра.** Подробности в `assets/README.md`.
  - **Подложка:**
    - бумага `tiles/paper.png` плиткой;
    - суша — бумага с полупрозрачной акварелью цвета государства;
    - море `tiles/sea.png` плиткой;
    - вдоль берега `strips/coast.png`.
  - **Ленты вдоль ломаных** через `epaint::Mesh`: квад на отрезок, `u` — накопленная длина, стыки mitre. Текстура повторяется по `u`.
    - кайма своего королевства `border-band.png`, чужих — `border-band-mask.png` с тинтом цветом государства;
    - дороги `road-cobble.png`;
    - реки `river.png`.
  - **Тушь векторная:** граница государства сплошная, провинции точками, уделы вассалов пунктиром. Контуры дрожат детерминированно: шум от координат точки, так что общая граница дрожит одинаково с обеих сторон.
  - **Полигоны:** невыпуклые триангулировать один раз (ear-clipping). Меши кэшировать и пересобирать, только когда меняются держатели земель.
- **Спрайты.**
  - **Атлас:** один атлас (скрипт рядом с `scripts/cut-sprites.py`, атлас и UV в RON) или загрузка PNG по одному — выбери меньший код. Размер атласа замерь.
  - **Постройки:** у постройки в `rules.ron` появляется поле `sprite`. Строящаяся рисуется полупрозрачной, сверху леса: `scaffold` или `fort-building` / `church-building`.
  - **Поселения:** спрайт по населению провинции, пороги в данных.
  - **Короны** над столицами государств.
  - **Природа:** горы, лес, поля, камыш. Задаётся в данных карты: поле провинции `terrain` и необязательные `rivers` — ломаные в RON.
  - **Метки состояния:** война на пограничной провинции (`camp`, `fire`), волнения (`revolt`), мор (`graves`), руины. Связь «флаг или ось → спрайт» — таблица в данных.
  - **Варианты** выбираются детерминированно по хешу id провинции.
  - **Порядок отрисовки** по нижней y, точка привязки внизу по центру.
- **Гербы.**
  - Щит `settlements/shield-*`. Маска поля вырезается из того же спрайта: заливка изнутри. Маска тинтуется цветом государства, сверху контур щита, корона над гербом.
  - Знамёна `banner-*` у гнёзд вассалов.
  - Гербы ориентированы по своей подписи: у вертикальной подписи герб стоит в её начале и повёрнут так же. Гербы одного ряда стоят на одной линии.
- **Убранство.**
  - Роза ветров, картуш королевства с названием и годом, угловые орнаменты, ветер, рыба и корабли в море.
  - Текст картуша, лент и табличек всегда влезает в подложку: шрифт и подложка подгоняются по ширине текста.
  - Шкалы-линейки нет.
- **Шрифт** подписей карты Cormorant SC (OFL), встроенный через `FontDefinitions`. Проверь кириллицу и вес wasm.
- **Камера:** масштаб колесом и сдвиг перетаскиванием уже есть с этапа 28, используй их. Клик по провинции через обратное преобразование. Крупный план провинции держит читаемость.
- **Цвета государств** различимы на пергаменте. Пурпуляндия сейчас похожа на красный цвет империи (заметка этапа 28).

## Не делать

- Новых растровых ассетов. Если чего-то не хватает, опиши в отчёте: координатор догенерирует.

## Приёмка
- Тест: у каждой постройки из `rules.ron` есть спрайт, и он есть среди ассетов. Так же проверяется каждое правило «флаг → спрайт».
- Тест: лента вдоль ломаной непрерывна по `u`, на стыке `u` конца отрезка равно `u` начала следующего.
- Тест: подпись королевства и год влезают в картуш для всех государств пресета. Так же для подписей на лентах.
- Тест: клик по своей провинции открывает карточку с её указами. У недоступного указа видна причина.
- Тест: клик по соседу открывает карточку войны и брака.
- Тест: каждое действие из бывшей боковой панели достижимо из какой-то карточки. Перечень строится по данным действий.
- Тест: гербы одного ряда имеют одну базовую линию.
- Скриншоты в `docs/ui-29/`: главный экран, карточка провинции, карточка соседа, карточка наследника, крупный план. Проверка в браузере без ошибок в консоли.
- Замерить размер wasm, атласа и шрифта (мягкие лимиты) и время кадра на большой карте.

## Ресурсы
Каждый cargo запускай только так: `systemd-run --user --scope -p MemoryMax=12G -p MemorySwapMax=0 -p CPUWeight=20 nice -n 10 bash -c '...'`. N потоков (`CARGO_BUILD_JOBS`, `-j`, `BD_THREADS`, `--test-threads`): 4, если параллельно работает другой агент, 8, если один. Никогда два cargo одновременно, `free -g` перед долгим прогоном. Долгие прогоны на переднем плане. trunk и headless chrome запускай только на время проверки.
