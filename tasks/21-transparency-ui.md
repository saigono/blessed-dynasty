# Этап 21. Прозрачность в UI

## Контекст
Прочитай CLAUDE.md, DESIGN.md, `docs/design/hidden-state.html` (раздел 7) и задачи 18–20. Граф, законы и симптомы уже влиты. Игрок должен видеть вектор, а не только значение, и понимать, что давит на королевство. Владелец собирается играть и решать, мало ли узлов.

## Вход
main после этапа 20. Сигнатуры `core` не менять. Новые функции и поля с serde(default) разрешены.

## Сделать
- **Прогноз в ядре.** Чистая функция: мир + N лет без событий дают значения узлов. Работает над копией, мир не меняет, детерминирована.
- **Панель осей.** Для каждой видимой оси:
  - стрелка тренда из 5 ступеней по изменению за 5 лет;
  - цель, к которой ось идёт;
  - «что давит» — два крупнейших вклада со знаком;
  - прогноз через поколение (30 лет).
  
  Пример в разделе 7 документа.
- **Скрытые узлы открываются по бюрократии.** Пороги из таблицы документа: 20, 40, 55, 70, 85, поле `reveal` у оси.
  - Открытый узел показывается словом из 5 ступеней («ничтожно, низко, средне, высоко, предельно») и стрелкой.
  - С бюрократии 85 видны числа и прогноз на 60 лет.
  - Закрытый вклад подписан «неясная причина» с подсказкой, какая бюрократия его откроет.
- **Панель законов.** Действующие законы. По каждому — что он держит и что усиливает, словами из данных.
- **Хроника и итоги года.** Пометка «Знамение» у симптомов. Цепочка причин в записях катастроф. В «Что решило судьбу» видны законы основателя.
- Все тексты на русском, в данных или в UI-константах, без хардкода id узлов в коде UI.

## Не делать
- Новые узлы и механику: только показ.

- Тест: пороги открытия.
- Тест: «что давит» выдаёт два крупнейших вклада со знаком.
- Тест: закрытый вклад подписан «неясная причина».
- Партия с вводом закона и чтением цепочки в хронике проходится мышью в браузере без ошибок в консоли. Скриншоты в `docs/ui-21/`.
