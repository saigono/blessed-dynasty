# Этап 10a. UI: экран правления и событие

## Контекст
Прочитай CLAUDE.md и DESIGN.md (раздел 10, мокапы 01 и 02 в артефакте дизайн-дока, если доступен; иначе по описанию в разделе 4). Этапы 2 и 3 завершены.

## Вход
Ветка main после этапа 3. Типы `Game`, `Step`, `EventView`, `World`, `Province` с полигонами. Сигнатуры не менять. Зависимости: `eframe`, `egui`, для веба `wasm-bindgen`, `trunk`. Больше ничего.

## Сделать
- `crates/ui`: `eframe` приложение, `App { game: Option<Game>, screen: Screen }`, `Screen = Start | Reign | Event(EventView) | ReignEnded`. `Start`: выбор пресета из списка и поле seed, кнопка «Начать».
- Экран правления. Верх: год и сезон, имя и возраст правителя, год правления, казна с доходом, армия, число провинций и сколько у короны. Центр: карта через `Painter` по полигонам из данных, цвет по держателю (корона, вассал, иностранная), слабая сила короны полупрозрачно, волнения красной обводкой, идущая стройка пунктиром; клик по провинции выбирает цель, имя провинции подписью. Справа: правитель с портретом-заглушкой и шкалой здоровья; оси столбиками; наследники с возрастом, способностью, претензией, статусом; соседи с отношением. Низ: кнопки действий из `available_actions`, выбор цели по клику на карте или из списка, строка «Действия k из n: идёт X, t из T лет», кнопка «Подождать год», кнопка «Отречься».
- Экран события: модальная карточка поверх затемнённой карты, заголовок, текст, варианты с краткими эффектами (оси со знаком), намёк серым внизу. Выбор вызывает `choose`, возврат на правление.
- `ReignEnded`: пока заглушка «Правление окончено: причина», кнопка «Снова». Этап 10b заменит.
- Шрифт с кириллицей встроить в бинарник (`include_bytes`), лицензия совместимая.
- Сборка: `trunk serve crates/ui` и `cargo run -p ui`.

## Не делать
- Хроника и счёт (10b). Анимации, темы, кастомные виджеты.
- Логика игры в UI. Любая проверка допустимости действия живёт в `core`.

## Приёмка
- Партия от старта до `ReignEnded` проходится мышью в браузере без ошибок в консоли.
- wasm-бинарник в release ≤ 8 МБ.
- Кадр с картой ≤ 16 мс на ноутбуке без дискретной графики (измерить `frame_time` egui, записать в отчёт).
