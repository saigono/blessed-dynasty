# Этап 3. Карта и соседи

## Контекст
Прочитай CLAUDE.md и DESIGN.md (раздел 5.2, 5.3). Этапы 0–2 завершены.

## Вход
Ветка main после этапа 2. Типы `World`, `Province`, `Holder`, `Neighbour`, `Stance`, `Event`, `Effect`, `Action`, `Game`. Сигнатуры не менять.

## Сделать
- `data/maps/default.ron`: 10 провинций короны и вассалов по DESIGN.md: Столица, Берг, Хольм (вассал Вейр), Арден (вассал Арден), Оствик, Лугово, Вейр (вассал Вейр), Гарт, Мар (вассал Арден), Сол. Три соседа: Нордмарк (3 провинции, север), Пурпуляндия (4, восток), Веструм (3, юго-запад), каждая провинция с `Holder::Foreign`. Соседство как граф, граница с иностранным государством = ребро к его провинции. Полигоны для UI в координатах 0..400 × 0..300 по мокапу из DESIGN.md.
- Пресет `default.ron` переключить на эту карту.
- Расстояние от столицы считается BFS при загрузке и кешируется в `Province` (поле `distance_to_capital: u32`).
- ИИ соседа: функция `neighbour_tick(&mut World, &Data, &mut Rng, NeighbourId)` раз в год. Переходы `Stance` по `relation` и сравнению `strength` с силой короны на границе; пороги в `rules.ron`. Выход: сдвиг `relation`, с вероятностью от стойки `SpawnEvent` одного из: ультиматум (`neighbour_ultimatum`), торговое предложение (`neighbour_trade`), набег на пограничную провинцию (`neighbour_raid`), объявление войны (`neighbour_war_declared`, само событие делает этап 4, здесь только спавн по id).
- Действия карты в `data/actions.ron`: `build_fort`, `build_road`, `build_market` (цель: провинция короны, эффект: постройка, сила короны, доход), `grant_province` (цель: провинция короны, эффект: держатель становится вассалом по выбору, лояльность знати вверх, сила короны вниз), `revoke_province` (цель: провинция вассала, обратное, лояльность знати сильно вниз), `marry_neighbour` (цель: сосед, `relation` вверх, флаг брака).
- Выбор вассала при раздаче: ближайший по графу существующий вассал, либо новый из списка имён в данных.

## Не делать
- Война как цепочка (этап 4). Здесь только спавн `neighbour_war_declared`.
- Генерация карт. Карта одна, в данных.
- Рисование. Полигоны только данные.

## Приёмка
- Тест: карта грузится, граф связен, у каждой провинции короны есть путь до столицы.
- Тест: сосед с `relation` ниже порога за 20 лет хотя бы раз спавнит событие, с высоким `relation` набег не спавнит.
- Тест: `grant_province` снижает силу короны провинции и повышает `loyalty_nobles`; `revoke_province` обратное.
- Тест: `build_fort` недоступен для провинции вассала.
