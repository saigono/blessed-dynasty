# Этап 8a. CLI-раннер

## Контекст
Прочитай CLAUDE.md и DESIGN.md (раздел 10.3). Этап 2 завершён. Этапы 6 и 7 могут быть не готовы, тогда соответствующие части печатаются как «недоступно».

## Вход
Ветка main после этапа 2. Типы `Game`, `Step`, `Decision`. Сигнатуры не менять. Новых зависимостей кроме `clap` не добавлять.

## Сделать
- `cli run --seed N --preset data/presets/default.ron --script path.ron`: грузит данные, создаёт `Game`, прогоняет скрипт решений, печатает журнал решений, затем хронику и счёт, если `sim` и `score` есть в `core`.
- Формат скрипта `data/scripts/*.ron`: список шагов `Wait(n) | Action(id, target) | Choose(idx) | ChooseByTag(cause_tag) | Abdicate`. `ChooseByTag` выбирает первый вариант с данным тегом, иначе индекс 0.
- Стратегия вместо скрипта: `--strategy neutral|crown_all|vassal_all|warmonger|builder`. В 8a реализовать только `neutral` (всегда средний вариант, действий нет). Остальные добавит 8b поверх `AutoChooser`.
- Вывод текстом в stdout, `--json` для машинного чтения.
- `cli replay --seed N --decisions file.json` воспроизводит партию из журнала `Decision` и печатает хэш итогового `World` для проверки детерминизма.

## Не делать
- Массовые прогоны, статистика, трассировка (этап 8b).
- Интерактивный режим.

## Приёмка
- Тест: `cli run` на тестовом скрипте завершается с кодом 0 и печатает хотя бы одно решение.
- Тест: `cli replay` дважды на одном журнале печатает одинаковый хэш.
